Monthly Agent Schedule

Create a 24×7 monthly roster using three equal 8-hour shifts. Each agent can work a maximum of five days per week, providing two weekly days off.

Agent Leave Management

Select an agent and leave date. The system first tries an available OFF agent, then a safe transfer from an overstaffed shift while preserving required staffing coverage.

Shift Swap Management

Select a date and two working agents. The system swaps their shifts only when both agents are on different shifts and the minimum rest-period rule remains safe.
